## 项目接力规矩（project-relay）

本工作区的每个子文件夹是一个项目。同一个项目可能由不同会话、不同账号、不同电脑或不同 AI 工具轮流推进，
所以**项目进度以磁盘上的项目卡 `PROJECT.md` 为准，不以某段聊天记录为准。**

- **动手前**：先读这个项目的 `PROJECT.md`（项目里有 `CLAUDE.md` / `AGENTS.md` 的也一起读）。它和你记得的不一样时，以项目卡为准。
- **每轮实际工作结束时**（产出成品、改了代码、做了决定）：更新项目卡，包括 `updated` 日期、当前进度、遗留问题、下一步，并在“相关对话”里补上本会话 ID 的前 8 位。只聊天、没有推进时不用改。
- frontmatter 里的 `title` 是左侧会话的名字，不要随便改。带 `parent:` 的是附属文件夹，进度写在主项目的卡里。
- 新建项目文件夹时，顺手建一张项目卡。
- 项目卡里不写 API Key、密码等机密。
- 不要两个会话同时推进同一个项目。
- 左侧会话列表空了或缺了：运行 `restore-projects` 重建。
